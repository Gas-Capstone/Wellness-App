# Features

- Home screen
  - Pulls info from other areas of the app, displaying in a central area
- Workout tracker with timer
  - Lists workouts in our database, with the ability to set a timer for completion
- Meal planner with ingredient tracker
  - Displays recipes from our database, alongside what you need to make them
  - Users can add ingredients to their fridge, and the app will automatically mark when you meet the ingredient requirement of a recipe
- Habit tracker, split into the days of the week
  - Lists habits for each day of the week, with the ability to mark habits as done for the day
  - Habits can be set to only be "active" on certain days of the week
